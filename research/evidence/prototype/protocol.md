# Frozen measurement protocol — 2026-11-06, before first prototype LLM run
Acme is development data already inspected in prior work, never a blind benchmark. Existing Korean/English gold is known to coordinator from prior work; modifier must not read it. Run final unchanged code twice with fresh output directories/caches, temperature 0, seed 7. Gold runs separate corpus, same code, no gold-label hints. Record code/input/reference/protocol SHA256. No tuning after evaluation; any fixes require new version and both runs and explicit development disclosure.

Types: denominator reference 9, prediction all exported types including extras. One-to-one semantic correspondence by source/granularity, no renaming to optimize metrics. Fixed aliases Account=Account/accounts; Contact=Contact/contacts; Invoice=Invoice/invoices; Subscription=Subscription/subscriptions; MonthlyUsage=ProductUsage/product_usage (only if account+month row); Ticket=Ticket/support ticket (log template); Plan=Plan/subscriptions.plan; Conversation=MeetingOrCall/Meeting/Call (document exchange); Commitment=Commitment/Promise/Obligation (asserted owed/promised act). Generic Request/Action/Feature/Credit are NOT automatically Commitment. Record exact mapping and evidence. Unmatched predictions false positive relative to reference; not necessarily false in reality.

Links: primary STRICT semantic directed precision/recall using all exported links as denominator and 11 reference links. Schema/FK value links map by columns (contact.account_id contact_at; invoice.subscription_id invoice_for; subscription.account_id subscription_of; subscription.plan on_plan; ticket.contact_id requested_by; ticket.account_id ticket_for; usage.account_ref usage_of). For document links, generic mentions or same-sentence is NOT attended_by/conversation_with/discussed/promised_to without a corresponding explicit supported relation. Secondary ENDPOINT projection deduplicates ordered endpoint pairs to show structural coverage; label clearly not semantic accuracy. Retain declared direct FK even if implied; inferred redundant link omissions reported.

Decisions: count emitted types + links once each. Code-only if no model output affects inclusion, identity, or endpoints. Otherwise LLM-dependent (including hybrid). Also report provenance counts per kind; do not claim percentage of reasoning effort.

Fact audit: select min(20,N) facts sorted by SHA256(canonical doc,section,sentence,subject,relation,object) from run1; reread original source text, ensure quoted evidence exists AND entire proposition (actor, negation, modality, object) is supported. Unsupported/ambiguous count incorrect. No exact-quote-only precision claim. Gold: independently score four promised acts with recipients (and due dates when present); traps are two denied promises. Report positive TP/4 and false accepted promises/2; rejected requests as requests are not trap failures. Also report exact preservation of dates and missing recipient. No gold-driven inference rules.

Execution: count uncached actual HTTP calls, cache hits, total wall time and summed LLM time, prompt input characters/UTF8 bytes, Ollama prompt_eval_count maximum, failures, completion truncation and docker logs containing truncating count since container launch. All calls must stay below observed ~4098 prompt limit and num_ctx 8192; byte upper bound guard before request. Empty/invalid results must be visible, not success.

Stability: compare canonical full ontology and fact sets across two independent runs; Jaccard types, semantic links, facts; cache hit count must be 0. Missing PDFs (3), nested NoSQL arrays if unsupported, free-form logs if unsupported, hierarchy/OWL/SHACL/rules absent must be explicit. Only source-derived transformed SQLite/JSONL/key-value logs and six Markdown docs used; no acme.json in inference.
